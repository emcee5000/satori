// hands on the keys

One rule to learn.

⌘ + a list's first letter moves the selected to-do there. Add ⌥ to go there instead. A status line shows the keys that work right now, and ? opens a cheat sheet.

// install

Up and running in a minute.

  1. Download Satori.zip, unzip it, and drag Satori.app to Applications.
  2. The first time, right-click Satori.app → Open and confirm. It's open source and not notarized, so macOS asks once.
  3. Press Space and start capturing.

Needs macOS 14 Sonoma or later. The download is for Apple silicon; Intel Macs can build from source.

build from source
# needs Xcode Command Line Tools
$ git clone https://github.com/emcee5000/satori.git
$ cd satori
$ ./scripts/build-app.sh --install
